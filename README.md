# 📰 News Application - React.js

## 📌 Project Overview
The **News Application** is a React-based project that fetches real-time news using an **external API**. It utilizes **React Router** for seamless navigation between different news categories, providing users with an intuitive browsing experience.

## 🛠 Technologies Used
- **React.js** (Component-based UI development)
- **React Router** (Navigation and routing)
- **External API** (Fetches live news updates)
- **CSS/Bootstrap** (Styling and responsiveness)

## 🚀 Features
### ✅ Core Features
- 🌍 **Fetches latest news** from an external API
- 🗂 **Category-wise Navigation** using React Router
- 🔄 **Live Updates** on news articles
- 📱 **Responsive UI** for all screen sizes
